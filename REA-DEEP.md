## 1. Printer / cash drawer / customer display
- **Stack BT: `flutter_blue_classic` (SPP/RFCOMM klasik, BUKAN BLE GATT).** Channel `id.co.esb.pos_lite/bluetooth_printer` + `.../usb_printer`. Model: `BluetoothDevice/BluetoothConnection`, bloc `bluetooth_printer_list_bloc`, UI `bluetooth_printer_list_bottom_sheet/dialog`.
- **UUID/service/characteristic: TIDAK ada di strings** (tak ada `00001101-…` SPP maupun UUID BLE `6E40000x/fee…`). Wajar: SPP Android (`createRfcommSocket`) tak perlu UUID di Dart; satu-satunya UUID mirip (`258EAFA5-…`) milik internal Flutter. Verifikasi butuh dekompilasi `flutter_blue_classic` / `esc_pos_generator.dart`, bukan strings.
- **Generator struk: `fnb_pos/src/utils/printer/{esc_pos_generator,printer_generator,star_prnt_generator}.dart`** (`EscPosGenerator`, `PrinterGenerator`, `StarPrntGenerator`, `getGeneratorByStation`, `printImageBytes`, `_printQR`). Bytecode ESC/POS (LF/GS-V/GS-(k) QR) ada di kode Dart terkompilasi, bukan string literal → tak terekstrak di sini.
- **Koneksi per station (`ms_station`):** `stationID PK, stationName, branchID, printerConnectionID→lk_printerconnection, printerTypeID→lk_printertype, printerName, printerPort (IP/port LAN, cth port 9100/SocketException), characterPerLine, printingModeID→lk_printingmode, localIdentifier (nama/BT MAC), flagActive, flagDefault`; `ms_station.flagAutocut` (+ `UPDATE ms_station SET flagAutocut=0 WHERE printerConnectionId=3` → ID 3 = tipe tanpa autocut). Setting "struk terpotong otomatis" = flag ini.
- **Cash drawer: perintah kick TIDAK ada di strings** (hanya `flagOpenCashdrawer` per COA/kategori + tombol `Open Drawer` + asset `open_drawer.webp`). Artinya kick = ESC/POS standar `ESC p m t1 t2` (`1B 70 00/01 …`) yang dikirim via koneksi printer struk (praktik umum; byte `1B 70` tak muncul literal di strings). `flagAuthorization` sepasang — buka drawer butuh otorisasi kasir.
- **Customer display: second-screen Flutter, bukan protokol VFD/serial.** Screen: `customer_display/{idle,main,order,payment_success}` + route `/dual-display-order-screen`, `/dual-display-payment-success-screen`; bloc `CustomerDisplayBloc/CustomerDisplayAppBloc`; tabel `ms_poscustomerdisplayhead (posCustomerDisplayID PK, … flagActive, responseBody)`, `…detail (imageUrl, imageBase64)`, `…application`; setting `('Local Setting','Enable Customer Display',0)` + `('POS','Customer Display Logo')`. Update via WS/event `updateCustomerDisplaySalesMenu`, bukan ESC/POS ke pole display.
