# Audit Penyelarasan Terminal — FINAL (terverifikasi silang 2026-10-17)

> FINAL 2026-10-17. Sintesis 5 audit paralel + `docs/AUDIT-TERMINAL-RBAC.md`, lolos kritik silang (6 temuan kritik sudah diperbaiki). Q6/Q7 dikonfirmasi user (lihat §4).

## 0. Model target final (beku untuk audit ini)

- 2 role: `owner`, `staff`. Owner membuat staff/branch/terminal.
- **5 tag terminal eksplisit**: `kasir`, `dapur`, `view_pelanggan`, `view_queue`, `full_access`. `full_access` = semua fitur kecuali halaman view pelanggan + terima 2 event (order-online-masuk DAN kitchen-incoming). Terminal legacy tanpa tag DIUSULKAN sebagai `full_access` (perlu konfirmasi).
- Tag mengatur ROUTING event/notifikasi, BUKAN feature gating (kasir/dapur/full = fitur penuh).
- `view_pelanggan` 1:1 ke satu kasir, satu halaman (cart + QR bayar live), SSE online-only. `view_queue` terikat branch, satu halaman antrean, SSE online-only.
- 1 device = 1 terminal = 1 printer. 1 terminal = 1 user = 1 device; claim men-kick sesi lama; 1 user boleh di N terminal.
- Bind device (branch→terminal→PIN terminal) SEKALI per device; login per sesi = username + password, lalu MODAL PIN staff (Q11 CLOSED 2026-10-17: berurutan, bukan 3 faktor sekaligus). Pindah branch = re-bind via tombol re-bind / keluar branch (Q12 CLOSED). Kick = login baru menang, sesi lama ditolak; notifikasi ke sesi baru yang fresh login (Q13 CLOSED).
- Identitas sale offline (Q7 CLOSED 2026-10-17, dikonfirmasi user): PK = UUIDv7 client-generated (unik global, terurut waktu); nomor `TRX-{BRANCH}-{TERM}-{YYYYMMDD}-{NNN}` sebagai display manusiawi; QR pembayaran bawa `client_id`; migrasi aditif + backfill; server upsert-by-client_id + konflik 409 terlihat.
- Kasir/dapur/full-access = AKSES PENUH semua fitur, tanpa kecuali (Q5 CLOSED 2026-10-17). Nav-lock DAPUR/DISPLAY eksisting harus dicabut; yang dikunci hanya view_pelanggan & view_queue (satu halaman masing-masing, sisanya hide dari sidebar profil view).
